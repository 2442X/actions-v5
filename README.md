# actions-v5
A toolkit for GitHub Actions on Vex V5 code.

## Directory Guide
### C++
[C++ Lint](cpp/cpp-lint.yml) - Lints C++ code & format

[C++ Build](cpp/cpp-build.yml) - Builds C++ code

[C++ Release](cpp/cpp-release.yml) - Makes a release for C++ updates

[C++ Docs](cpp/cpp-docs.yml) - Creates GitHub Pages Docs via Doxyfile

### Python
[Python Lint](python/py-lint.yml) - Lints Python code & format

[Python Syntax](python/py-syntax.yml) - Python syntax checker

[Python Tests](python/py-tests.yml) - Python unit tester

### Common
[Codespell](common/codespell.ym) - Checks for typos in code via Codespell
